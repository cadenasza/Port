MaisAbrigo API

Sistema de Gerenciamento de Abrigos em Emergências com IoT

🎯 Sobre o Projeto

API REST completa para gerenciamento de pessoas resgatadas e abrigos em situações de emergência. O projeto combina uma plataforma web robusta, tecnologia IoT e dashboard analítico em tempo real para apoiar a Defesa Civil, voluntários e cidadãos em momentos críticos.

Esta solução inovadora utiliza sensores IoT para monitoramento automático de ocupação e condições ambientais, proporcionando informações precisas para tomada de decisão em situações de emergência.

🚀 Funcionalidades Principais

👥 Cadastro de Pessoas Resgatadas

  • Registro completo com nome e idade
  • Condições de saúde documentadas
  • Associação com abrigos específicos (relacionamento 1:N)
  • Histórico de localização e transferências

🏠 Gestão de Abrigos

  • Cadastro detalhado: nome, endereço e capacidade
  • Controle de recursos disponíveis (comida, água, leitos)
  • Monitoramento de ocupação atual em tempo real
  • Atualização automática via sensores IoT

📲 Integrações e Inovações

📡 Internet das Coisas (IoT)

  • Sensor de Presença: Detecta entrada e saída de pessoas, atualizando automaticamente a ocupação do abrigo
  • Sensor de Temperatura: Monitora condições ambientais em tempo real
  • Protocolo MQTT: Comunicação eficiente entre dispositivos
  • Plataformas: Integração com Node-RED e Thinger.io
  • Hardware: Arduino e ESP8266 para coleta de dados

📊 Dashboard para Defesa Civil

  • Visualização em tempo real da ocupação de cada abrigo
  • Gráficos de temperatura ambiente
  • Estatísticas de número de abrigados
  • Alertas automáticos de capacidade máxima
  • Interface intuitiva desenvolvida com Node-RED ou Thinger.io

🧱 Stack Tecnológica

  • Backend API: ASP.NET Core MVC
  • Banco de Dados: Oracle Database
  • ORM: Entity Framework Core (Code-First)
  • IoT: Node-RED, MQTT, Arduino, ESP8266
  • Dashboard: Node-RED / Thinger.io
  • Documentação: Swagger / OpenAPI
  • Views: Razor Pages + TagHelpers

🗄️ Arquitetura

  • Models: Entidades Abrigo e Pessoa com relacionamento 1:N
  • DTOs: Objetos de transferência para entrada e resposta da API
  • Controllers: Endpoints RESTful seguindo boas práticas
  • DbContext: Configuração EF Core com migrations
  • Swagger: Documentação interativa dos endpoints

🧪 Principais Endpoints REST

  • GET /api/abrigo - Lista todos os abrigos
  • POST /api/abrigo - Cria um novo abrigo
  • GET /api/pessoa - Lista pessoas resgatadas
  • POST /api/pessoa - Cadastra uma nova pessoa
  • GET /api/abrigo/{id}/ocupacao - Consulta ocupação em tempo real

💡 Impacto Social

Este projeto foi desenvolvido com foco em auxiliar a gestão de crises humanitárias, proporcionando ferramentas tecnológicas modernas para:

  • Otimizar a distribuição de recursos em situações de emergência
  • Facilitar o trabalho da Defesa Civil e equipes de resgate
  • Garantir condições adequadas para pessoas em abrigos
  • Fornecer dados precisos para tomada de decisão rápida
